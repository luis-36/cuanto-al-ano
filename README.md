# Al Año — Calculadoras de lo que de verdad te cuesta

Sitio estático HTML optimizado para **Google AdSense** + tráfico recurrente (México / LATAM).

## Contenido

- 6 calculadoras interactivas (cigarros, café, streaming, tarde, ahorro, delivery)
- 4 guías largas (gastos hormiga, fumar, suscripciones, ahorro)
- Privacidad, aviso legal, sobre
- `ads.txt` + `sitemap.xml`
- Diseño móvil, sin registro, resultados copiables

## Subir a Vercel

1. Sube la carpeta a GitHub
2. Importa en Vercel → Framework: **Other** → sin build
3. Sustituye en `ads.txt` tu `pub-XXXX`
4. Sustituye en `sitemap.xml` `TU-URL.vercel.app` por tu dominio real
5. Añade el script AdSense en el `<head>` cuando tengas `ca-pub-...`
